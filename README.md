# 🧮 Calculadora Científica en C#

## 🎯 Descripción General

Este proyecto consiste en una **calculadora científica de escritorio** desarrollada en **C# (.NET Framework)**.  
Cuenta con una interfaz gráfica funcional que permite realizar operaciones matemáticas básicas y avanzadas, integrando una función de **actualización dinámica** de funcionalidades mediante un botón especial.

---

## 🗂️ Estructura del Proyecto

El repositorio contiene dos partes principales:

### 📁 Carpeta principal del proyecto  
Contiene la base funcional de la calculadora con operaciones matemáticas científicas básicas como:  
- Suma, resta, multiplicación, división  
- Funciones trigonométricas (sin, cos, tan)  
- Potencias, raíces, logaritmos, etc.

### 🔄 Funcionalidad de Actualización  
Un botón adicional que permite agregar nuevas funciones a la calculadora automáticamente recordar cambiar la ruta.  
Esto permite que la aplicación se mantenga en crecimiento sin necesidad de reconstruir desde cero.

---

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** C#  
- **Framework:** .NET Framework (WinForms)  
- **IDE recomendada:** Visual Studio 2022 o superior

## 🔄 Función de Actualización

El botón de **Actualizar** permite agregar nuevas funcionalidades de manera automática sin necesidad de modificar manualmente el código base.  
Lo que permite:

- Nuevas funciones científicas
- Mejoras en el diseño de interfaz
